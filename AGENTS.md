# AGENTS.md

ZMK firmware configuration for the Eyelash Sofle split keyboard.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`limiu82214/zmk-sofle`), accessed via
the `gh` CLI. External pull requests are also treated as a request surface. See
`docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: the five canonical state roles are used verbatim as label
strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`,
`wontfix`), alongside the `bug` / `enhancement` category labels. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. Neither exists
yet; they get created lazily when terms or decisions actually need recording.
See `docs/agents/domain.md`.
